# Apple integration and client compatibility — 2026-10-25

## Decision

Keep MCP as the agent interface, ship the CLI for deterministic scripts/long uploads, and package MCP plus workflow instructions as a plugin. These are complementary layers. No remote HTTP server, new service account or public endpoint is needed for local workflows. Build and signing stay with Xcode/CI.

The old hand-written wrapper covered a small part of Apple's API. Release 0.2.0 adds a pinned, searchable OpenAPI catalog with separate validated read/write execution; frequent TestFlight tasks receive named tools. The specification downloaded from Apple on 2026-10-25 reports API 4.5.1 and 1303 operations. Coverage means reachable operations, not live verification of every operation. Build/file transfers and the App Store submission sequence have behavioral tests; production checks use reads.

## MCP

The current published specification is **2026-07-28**. It introduces a stateless core, cacheable lists, header routing, multi-round-trip requests and an extension framework. The TypeScript SDK is split into `@modelcontextprotocol/server` and `@modelcontextprotocol/client`; npm reported **2.4.0** for both. This release migrates the server to `serveStdio`, Zod 4 schema objects and the v2 SDK while serving legacy clients from the same factory. Both modern SDK 2.4 and legacy SDK 1.32.2 clients are exercised by smoke scripts.

Sources: [MCP release](https://blog.modelcontextprotocol.io/posts/2026-07-28/), [TypeScript migration](https://ts.sdk.modelcontextprotocol.io/v2/migration/upgrade-to-v2.html), [stdio and legacy serving](https://ts.sdk.modelcontextprotocol.io/v2/serving/stdio.html).

## Codex

The running desktop updater reported **26.1021.31345 / build 21828**, production channel, **up_to_date**. This is the app's configured-channel result. The working standalone binary at `~/.local/bin/codex` reports **0.153.4**; npm and the official release feed report **0.164.0**, published October 23. The login shell's bare `codex` resolves to a stale Homebrew/npm shim with a missing native executable; use the working explicit path for plugin management. No Codex client installation or configuration replacement is part of the MCP release.

Current plugin packaging supports a portable root `plugin.json`/`mcp.json`; `.codex-plugin/plugin.json` remains a supported compatibility fallback. The updated local package provides both. Plugin identity/versions and CLI availability are verified during installation. The currently running chat retains its discovered tools; a new chat loads the new server catalog.

Sources: [Codex changelog](https://developers.openai.com/codex/changelog/), [plugin packaging](https://developers.openai.com/plugins/build/plugins), local updater and binary version probes.

## Claude Code

The installed CLI reports **2.1.250**; npm and the official changelog report **2.1.310**. Current Claude docs describe v1/v2 MCP runtimes, protocol 2026-07-28, dynamic tool updates, reconnection and server-side tasks. Later releases broaden v2 defaults and fix protocol result/list compatibility. The new MCP also serves the legacy handshake, so updating Claude is not required for this local rollout. Existing Claude registration already points to the shared launcher; reconnect it to load the new build. No unrelated Claude configuration is changed.

Sources: [Claude MCP documentation](https://code.claude.com/docs/en/mcp), [official changelog](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md), local version probe.

## Apple

Build Upload API is public and was introduced in API 4.1 / WWDC25. TestFlight groups, memberships, invitations, beta review, provisioning, app metadata and review submissions have public endpoints. Initial ASC app-record creation still requires Apple's website. Some older Apple overview prose still says binary uploads require Transporter; the newer Build Upload API documentation and API 4.1 release notes supersede that upload limitation.

Sources: [Apple API overview](https://developer.apple.com/documentation/appstoreconnectapi/), [4.1 release notes](https://developer.apple.com/documentation/appstoreconnectapi/app-store-connect-api-4-1-release-notes), [WWDC25](https://developer.apple.com/videos/play/wwdc2025/324/), [app-record limitation](https://developer.apple.com/documentation/appstoreconnectapi/apps).
